# Nova Deep Market Agent

**AI Market Analysis Agent for Binance Agent OS Mini Hackathon – Track A**

---

## Overview

Nova Deep Market Agent is an advanced crypto market intelligence agent designed for deep, structured analysis of major cryptocurrencies.

It provides professional-grade market analysis covering:

- Market Snapshot
- Multi-Timeframe Trend Analysis
- Key Support & Resistance Levels
- Market Structure & Price Action
- Momentum & Sentiment
- Risk Assessment
- What to Watch Next
- Clear Bias Summary

---

## Features

- Deep structured analysis for BTC, ETH, and major altcoins
- Multi-timeframe trend view (Short-term + Medium-term)
- Clear support/resistance levels with reasoning
- Risk assessment and invalidation levels
- Comparison between coins (when requested)
- Clean and professional response format
- Built for clarity and decision support (not financial advice)

---

## How It Works

This agent runs on **Claude** using a carefully engineered system prompt.  
It is designed to deliver consistent, high-quality market analysis suitable for the Binance Agent OS ecosystem (Track A – Data & Analysis).

---

## Example Usage

**User:**  
Give me a deep market analysis of BTC

**Agent:**  
Returns a full 8-section structured analysis including bias and key levels.
